## Key Information

**APE Senegal Bonds:**
- Minimum: 10,000 FCFA
- Terms: 3/5/7/10 years
- Rates: 6.40% - 6.95%
- Semi-annual interest payments

**Sama Naffa Platform:**
- Mobile-first financial services
- Wallet, savings, tontines, joint accounts
- Target: Senegalese market with UEMOA expansion
