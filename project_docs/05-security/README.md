## Security Highlights

### Authentication
- JWT with refresh tokens
- OTP via SMS/Email
- Multi-factor auth for admin

### Data Protection
- AES-256 encryption at rest
- TLS 1.3 in transit
- RBAC access controls

### Compliance
- GDPR-aligned data handling
- Senegalese banking regulations
- Regular penetration testing
